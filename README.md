# PyPython Academy

A premium, gamified React + Vite Python learning platform inspired by the official Python tutorial. The app includes chapter module cards, a playful buddy mascot, persistent progress, lesson routes, analytics, profile exports, and an in-browser Python runner powered by Pyodide.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features

- React + TypeScript + Vite frontend
- Tailwind CSS styling with dark premium dashboard
- Framer Motion animations and buddy character reactions
- React Router navigation for Home, Module Detail, Lesson, Analytics, and Profile pages
- Axios API wrapper with local fallback persistence
- Prism.js syntax highlighting and an interactive code editor
- Full curriculum map covering all 13 chapters / 52 lessons from the Python tutorial
- LocalStorage-backed progress history so learners can continue where they left off
